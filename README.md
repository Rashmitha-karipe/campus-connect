# Campus-Connect

Roles: **student** (browse + register), **organizer** (request events), **admin** (approve/reject).
Stack: HTML, CSS, JS · Node.js + Express · SQLite · JWT.

## Run it
1. Install Node.js (LTS) from https://nodejs.org
2. In this folder run:  `npm install`
3. Start:  `npm run dev`   (or `npm start`)
4. Open http://localhost:3000

Default admin: **admin@campus.com** / **admin123** (change this!)
Sign up a student and an organizer from the register page to test the full flow.
